# dsh-novel-reader

本地电子书阅读器 + 摸鱼伪装：在 DSH 右侧边栏读自己的书，按窗口大小自动分页、翻页阅读，并记住每本书读到第几页；默认把阅读界面伪装成一份 WPS 经营分析文档，需要时一键全屏切成 Excel 表格。

仓库：<https://github.com/AlexXZQ/dsh-novel-reader>

![文档伪装](docs/disguise.png)

## 摸鱼伪装

- **文档伪装（默认开启）**：阅读区变成一份经营分析报告——假文档名、WPS 菜单栏、页眉页脚、水印、页码、章节编号、访谈引文样式，以及按段落插入的区域渠道表格；标签页标题从 `阅读` 变成 `经营分析`，侧栏底部按钮从 `阅读` 变成 `文档`，窗口标题变成 `xxx.docx - WPS Office`。
- **老板键**：在阅读区按 `Esc`，或在任意位置按 `Ctrl+Shift+X`，整个窗口立即被一张全屏 Excel 表盖住；再按 `Esc` / `Enter` / `Ctrl+Shift+X`，或点右上角的 `×` 返回。
- **切换**：在阅读区按 `B` 在「文档伪装 / 阅读视图」之间切换；也可以点 `Aa` 阅读设置里的「文档伪装」。选择会保存，下次打开沿用。
- 老板键的表格、文档名和数据都是本地生成的假数据，不包含任何真实业务数据，也不联网。

![表格伪装](docs/boss.png)

## 阅读功能

- **自动分页**：每章按当前窗口大小和字号自动切成多页，翻页阅读，不需要上下滚动；拉宽/缩窄侧栏或调整字号后会自动重排，并保持当前阅读位置。
- **翻页**：上一页 / 下一页；到章末再翻会进入下一章第一页，到章首再翻会回到上一章最后一页。支持底部按钮、鼠标滚轮、方向键和 `PageUp` / `PageDown`。
- **打开本地电子书**：`TXT` / `Markdown` / `EPUB`，点击选择或直接把文件拖进面板。
- **记住阅读进度**：每本书分别保存「第几章 + 本章页码比例」，关闭 DSH 或重启后再次打开会自动回到上次的位置；窗口大小变化后也能按比例落回同一处。
- **书架**：最近在读置顶，显示章节数、字数、上次阅读时间和阅读百分比，支持移除。
- **阅读体验**：目录筛选跳转、全书进度、三种背景（纸白/米黄/夜间）、四种字体、字号与行距调节；设置自动保存。
- **编码**：UTF-8 / UTF-16 / GB18030 / GBK / Big5；EPUB 支持 EPUB 3 导航目录与 EPUB 2 NCX 目录。

### 快捷键

| 键 | 作用 |
|---|---|
| `PageUp` / `PageDown` | 上一页 / 下一页（跨章连续） |
| `↑` / `↓` / `←` / `→` | 上一页 / 下一页 |
| `Home` / `End` | 本章第一页 / 最后一页 |
| `[` / `]` | 调整字号（自动重新分页） |
| `B` | 在阅读区切换文档伪装 / 阅读视图 |
| `Esc` | 在阅读区打开全屏表格伪装 |
| `Ctrl+Shift+X` | 任意位置打开/关闭全屏表格伪装 |

阅读清楚、不要伪装时按 `B` 即可回到干净的阅读界面：

## 数据

书籍正文和阅读进度都保存在本机 DSH 插件数据目录，不上传：

```
~/.dsh/plugin-data/dsh-novel-reader/
├── library.json        书架索引 + 每本书的阅读进度
└── books/<id>.json     章节与段落
```

删除某本书时，对应文件一并删除。卸载插件不会自动删除这些数据。

## 结构

- **Host（`index.js`）**：提供 `/api/novel-reader` 路由（书架、书籍内容、进度、删除），把归一化后的书籍和进度以原子写方式持久化。
- **Client（`client.js`）**：注册右侧边栏标签页类型 `novel`、标签页标题、侧栏底部按钮、引导卡片，以及覆盖全窗口的 `shell.overlay` 表格伪装层；在页面内解析 TXT / Markdown / EPUB，渲染阅读界面并节流保存进度。

## 依赖与实现

- 解析 EPUB 只用浏览器内建的 `DecompressionStream` 与 `DOMParser`，不引入第三方库。
- 书籍大小上限 80 MB（导入时），Host 侧请求体上限 96 MB。
- 文档伪装与表格伪装全部在客户端渲染，不改动 Host 数据。

## 安装

要求：DSH Web / Desktop 0.2+，Node.js 20+，本机可用 `git`。

### 从 GitHub 安装（推荐）

```text
plugin_manager(action: "install_bundle", target: "github:AlexXZQ/dsh-novel-reader")
```

安装完成后，右侧边栏的引导页会出现 `本地阅读器` 卡片，侧栏底部也会出现 `阅读` / `文档` 按钮。

如果安装时 DSH 窗口已经打开，刷新一次窗口（`Ctrl+R`）以加载最新的客户端代码。

也可以先克隆再按本地目录安装：

```bash
git clone https://github.com/AlexXZQ/dsh-novel-reader.git
```

```text
plugin_manager(action: "install_bundle", target: "<克隆后的绝对路径>")
```

### 本地安装（开发）

把本目录作为本地 bundle 安装到当前 profile：

```text
plugin_manager(action: "install_bundle", target: "<本目录绝对路径>")
```
